BlockPojav Java Alpha — самостоятельная основа приложения без Zalith Launcher 2.

Сейчас реализованы: собственный Android-интерфейс на Java, сохранение ника и версии, настройка лимита памяти с ограничением по доступной RAM, кнопка щадящего профиля, загрузка официальных vanilla-файлов версии (клиент, Java-библиотеки и ресурсы) с проверкой SHA-1 и учётом статуса установки.

Пока НЕ реализованы: Java Runtime для Android, графический слой, запуск игрового процесса и Microsoft OAuth. Кнопка слабого устройства пока меняет только безопасный лимит памяти; она не меняет графические настройки Minecraft, поскольку игра ещё не подключена.

СБОРКА ЧЕРЕЗ GITHUB
1. Распакуй ZIP на компьютере.
2. В репозитории GitHub нажми Add file → Upload files.
3. Открой распакованную папку BlockPojav_Java и перетащи ВСЁ её содержимое в окно GitHub. Должны загрузиться app, .github, build.gradle, settings.gradle и gradle.properties. Не загружай сам ZIP.
4. Нажми Commit changes.
5. Открой вкладку Actions и выбери Build BlockPojav Java Alpha. Дождись зелёной галочки.
6. Открой завершившуюся сборку, внизу страницы скачай BlockPojav-Java-Alpha-APK и распакуй ZIP. Внутри будет APK.

Если репозиторий уже содержит старые файлы, сначала лучше создать отдельный пустой репозиторий, чтобы старый workflow не запускался вместе с новым.

Требования сборки: Android Gradle Plugin 8.7.3, Java 17, compile SDK 35. GitHub workflow устанавливает Gradle 8.9 автоматически.
