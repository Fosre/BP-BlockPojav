BLOCKPOJAV: ИНСТРУКЦИЯ ПО ЭТАПАМ

СЕЙЧАС: ЭТАП 1 — собрать Java-основу APK через GitHub

В первой сборке уже было:
- самостоятельный Java-интерфейс BlockPojav;
- сохранение ника и выбранной версии;
- настройка лимита памяти с учётом доступной RAM;
- кнопка «Для слабого устройства»;
- GitHub Actions, который собирает APK.

Внимание: этот этап ещё не запускает Minecraft. Установка файлов игры, Android Java Runtime, графика, игровой процесс и вход Microsoft будут добавляться отдельно.

КАК ЗАГРУЗИТЬ В ТВОЙ GITHUB

1. Скачай и распакуй BlockPojav_Java_Alpha.zip на компьютере. Внутри появится папка BlockPojav_Java.
2. Открой репозиторий Fosre/BP-BlockPojav на GitHub и перейди на вкладку Code.
3. Если GitHub показывает Quick setup для пустого репозитория, нажми ссылку «uploading an existing file».
   Если репозиторий уже содержит файлы: нажми Add file → Upload files.
4. Открой папку BlockPojav_Java на компьютере. Выдели и перетащи ЕЁ СОДЕРЖИМОЕ в окно загрузки GitHub. Загрузи папки и файлы внутри, а не ZIP и не одну папку-обёртку.
   В корне GitHub должны появиться: app, .github, build.gradle, settings.gradle, gradle.properties и README_RU.txt.
5. Если GitHub спросит заменить .github/workflows/android.yml, соглашайся на замену. Так новая сборка Java заменит workflow, который раньше загружал Zalith.
6. Внизу страницы нажми Commit changes. Оставь ветку main и подтверди сохранение.
7. Открой вкладку Actions. Выбери самый свежий запуск «Build BlockPojav Java Alpha» и дождись завершения.
8. Если рядом зелёная галочка: открой запуск, прокрути вниз до Artifacts и скачай BlockPojav-Java-Alpha-APK.
9. Распакуй скачанный ZIP. Файл .apk внутри можно передать на Android и установить.

ЕСЛИ НЕ ВИДИШЬ ACTIONS
- Открой вкладку Actions в репозитории и нажми «I understand my workflows, go ahead and enable them», если GitHub предложит.
- Убедись, что загружен именно файл .github/workflows/android.yml и он находится в корне проекта по этому пути.
- Если сборка красная, открой её, нажми на шаг Build APK и пришли сюда скриншот красной ошибки или скопируй последние строки.

ОБНОВЛЕНИЕ: ЭТАП 2 УЖЕ ДОБАВЛЕН В НОВЫЙ АРХИВ

Новая версия проекта содержит загрузку официальных файлов Minecraft: метаданных версии, клиентского файла, библиотек и ресурсов. Файлы проверяются по SHA-1, после загрузки кнопка меняется с «УСТАНОВИТЬ» на «ИГРАТЬ». При этом кнопка «Играть» пока только сообщает, что запуск ещё не подключён.

Чтобы получить изменения, загрузи обновлённое содержимое папки BlockPojav_Java в свой GitHub ещё раз с заменой файлов, затем дождись новой сборки Actions. В установленном приложении выбери версию и нажми «УСТАНОВИТЬ». Нужен интернет и свободное место; загрузка ресурсов может занять время.

ЧТО БУДЕТ ДАЛЬШЕ ПО ЭТАПАМ

Этап 2. Добавлен в обновлённый архив: загрузка файлов официальной vanilla-версии и отображение статуса установки.
Этап 3. Подобрать Android Java Runtime и графические компоненты, необходимые для запуска Minecraft на телефоне. Это самая сложная часть; будем выбирать совместимые открытые компоненты и сохранять их авторские уведомления.
Этап 4. Подключить запуск выбранной версии и проверить его на устройстве.
Этап 5. Добавить официальный Microsoft-вход и проверить доступ к Minecraft Java Edition. Обход покупки и авторизации не делаем.
Этап 6. Связать «Для слабого устройства» с реальными параметрами запуска и графики, затем настраивать сенсорное управление.

Результат Этапа 1: APK устанавливает только приложение BlockPojav Alpha. Наличие APK само по себе не означает, что Minecraft уже запускается.
